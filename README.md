# Rabecca Mulinda — Portfolio

Personal portfolio of Rabecca Mulinda, Senior Software Engineer in Lilongwe, Malawi.

Built with React and Vite.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

## Editing content

All text (experience, projects, skills, services) lives in `src/data.js`.
SEO tags are in `index.html`; `public/robots.txt` and `public/sitemap.xml` hold the site URL too.
